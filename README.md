idvault is a free knowledge graph GUI tool focused on media files, allowing user to procedurally create, search, relate and semantically specialize data and media locally for future reference.

The tool is made in Godot 4 without addons, using vanilla GDScript and it's licensed under GPLv2.

***

# Roadmap

idvault is currently undergoing foundational development and it's very unstable and bare-bones, but it aims to have implemented all those features below by version stable 1.01:
- Action system that performs most of the user tasks;
- Create and manage vaults; 
- Create, relate and modify items and their properties in bulk;
- Link between items and query them effortlessly;
- Export one, multiple, staged or all items to universal formats (JSON, CSV, TXT) in chunks or combined;
- Default UI with reorderable panels that display item data in different ways, allows users to implement custom UI if needed;
